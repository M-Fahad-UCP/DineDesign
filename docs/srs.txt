Project Idea : Approved
Abstract
DineDesign is a multi-tenant SaaS platform that enables restaurants to build their own website and mobile app, manage their online menu, accept online orders, process payments, and handle reservations. The system integrates with JazzCash, Easypaisa, WhatsApp API, and SMS Gateways, providing a unified and localized digital solution for Pakistan’s restaurant industry.
The platform includes the Menu Management Module, Ordering Module, Reservation Module, Loyalty Module, Notification Module, Admin Dashboard, and AI Branding Module.
Introduction and Background
Product (Problem Statement)
Restaurants in Pakistan cannot easily create online digital presence with local payment integration. They rely on expensive aggregator platforms, reducing profit margins.
DineDesign provides an integrated SaaS solution enabling online menus, ordering, reservations, AI branding, and analytics.
Background
Local restaurant owners lack affordable, easy-to-use digital platforms. International platforms like Wix or Squarespace do not support JazzCash or Easypaisa, and aggregators charge 25–35% commissions.

Performance Requirements
The system must respond to menu browsing requests within 2 seconds for up to 500 concurrent users.
Checkout and payment processing via JazzCash or Easypaisa should complete within 5 seconds under normal network conditions.
Notifications (SMS or WhatsApp API) should be delivered within 30 seconds of triggering an event.
System uptime must be at least 99.5% per month.
Database queries (menu retrieval, order history) must return results in <1 second for single tenant queries.
Rationale:These requirements ensure smooth user experience, prevent order delays, and maintain customer trust.
Safety Requirements
Customer personal data (name, contact, order history) must be securely stored in MongoDB Atlas.
Only authorized admin users can modify menu or order data.
Backup of orders and reservations must be performed daily to prevent data loss.
Table reservations cannot be double-booked.
Safeguards:
Use secure HTTPS connections for all communications.
Implement role-based access control for admin/staff.
Data validation to prevent accidental overwrites or deletions.
Security Requirements
All API calls must be authenticated using JWT tokens.
User passwords must be hashed and stored securely.
Payment integration must comply with JazzCash and Easypaisa security standards.
Admin dashboard should have 2-factor authentication for access.
All sensitive data must be encrypted at rest and in transit.
Rationale:These requirements ensure data privacy, prevent unauthorized access, and comply with financial regulations.
Additional Software Quality Attributes
Reliability: System must recover automatically from crashes; recovery time < 5 minutes.
Scalability: Must handle up to 1000 concurrent users without performance degradation.
Usability: Web and mobile interfaces should be intuitive; average user task completion ≤ 2 minutes.
Maintainability: System modules (Menu Management, Ordering, Reservation) must be modular for easy updates.
Interoperability: Must integrate with external systems (JazzCash, Easypaisa, WhatsApp API, SMS Provider).
Testability: Each module must have unit and integration test coverage ≥ 80%.
Portability: Web system should support Chrome, Edge, Firefox; mobile apps on Android/iOS.
